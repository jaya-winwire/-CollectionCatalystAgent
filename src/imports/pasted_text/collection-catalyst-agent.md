Build an AI-Powered Collection Catalyst Agent (React + Tailwind CSS)
Objective

Design and develop a modern, enterprise-grade AI-powered Accounts Receivable Collections platform called:

Collection Catalyst Agent

This solution helps finance teams intelligently prioritize overdue invoices, generate AI-assisted payment reminders, recommend payment plans, automate collection workflows, and support manager approvals.

The application should provide an AI-first experience inspired by Vercel AI, Linear, Stripe Dashboard, Notion AI, OpenAI ChatGPT, and Microsoft Copilot, while using Tailwind CSS for a clean, modern interface.

Avoid Fluent UI styling.

Business Goals
Prioritize overdue invoices using AI-powered risk scoring.
Generate personalized payment reminders with Azure OpenAI.
Recommend intelligent payment plans based on customer history.
Automate end-to-end collection workflows using Power Automate.
Support human-in-the-loop approvals for governance.
Provide real-time dashboards, analytics, and AI insights.
Improve cash flow, reduce manual effort, and increase collection efficiency.

Design Goal: Create a premium, AI-first enterprise application with a clean Tailwind CSS aesthetic, modern cards, intuitive navigation, conversational AI interactions, and responsive dashboards. The experience should feel like a blend of Vercel AI, Stripe, Linear, and GitHub Copilot, while remaining optimized for enterprise finance teams.
